Model logic

C = c₀ + c₁(Y − T)
AE = C + I + G + NX
AE = (c₀ − c₁T + I + G + NX) + c₁Y
Y* = (c₀ − c₁T + I + G + NX) / (1 − c₁)
Spending multiplier = 1 / (1 − c₁)
Tax multiplier = −c₁ / (1 − c₁)

The green dashed expenditure schedule represents the saved baseline, and the blue schedule represents the current slider settings. Use “Set current values as baseline” to start a new comparison. If c₁ changes, the AE slope and multiplier change, so ΔY need not equal the original spending multiplier times the change in autonomous spending. At equilibrium, planned aggregate expenditure equals output (AE = Y). Above the 45-degree line, planned spending exceeds production and inventories fall, encouraging firms to raise output. Below it, inventories accumulate and firms reduce output. Lump-sum taxes affect consumption through disposable income; net exports are autonomous here.
